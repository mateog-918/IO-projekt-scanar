# API Documentation (Swagger)

This guide explains how to access and use the interactive Swagger UI documentation for the SCANAR API.

---

## Prerequisites

The backend server must be running. If not already started, follow the [Setup Instructions](../Setup.md).

---

## Accessing Swagger UI

1. Ensure the backend is running:
   ```bash
   cd backend
   python app.py
   ```

2. Open your browser and navigate to:
   
   **http://localhost:5000/apidocs/**
