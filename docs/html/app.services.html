app.services.face_recog module¶

Face Recognition Service¶

This module provides utility functions for handling face encodings, including conversion between binary storage and NumPy arrays, and logic for matching embeddings against stored employee data.

app.services.face_recog.get_face_encodings(emp: Employee) → ndarray[source]¶

Retrieves all available face encodings for a given employee.

Scans all five potential encoding slots in the Employee model and decodes any that are not null.

Parameters:

emp (Employee) – The employee instance to scan.

Returns:

A 2D array of shape (N, D) where N is the number of encodings found and D is the vector dimension. Returns an empty array if none found.

Return type:

np.ndarray

app.services.face_recog.matches_embedding(emp: Employee, query_vec: ndarray, threshold: float = 0.6, metric: str = 'euclidean') → bool[source]¶

Compares a new face embedding against all stored encodings for an employee.

Parameters:

  • emp (Employee) – The employee to verify against.

  • query_vec (np.ndarray) – The encoding vector from the camera.

  • threshold (float) – The maximum distance to consider a ‘match’. Lower is stricter. Defaults to 0.6.

  • metric (str) – The distance calculation method (‘euclidean’ or ‘cosine’).

Returns:

True if any stored encoding is within the threshold distance.

Return type:

bool

Raises:

ValueError – If an unsupported metric is provided.

app.services.face_recog.matches_face_image(emp: Employee, image_bytes: bytes, tolerance: float = 0.6) → bool[source]¶

Processes a raw image and checks if it matches the stored employee encodings.

This is a high-level wrapper that performs face detection and encoding extraction before calling matches_embedding().

Parameters:

  • emp (Employee) – The employee to verify.

  • image_bytes (bytes) – Raw bytes of the image (e.g., from a request).

  • tolerance (float) – Matching strictness. Defaults to 0.6.

Returns:

True if a face is detected and matches.

Return type:

bool

Raises:

RuntimeError – If the face_recognition library is not installed.
