app.api.auth module¶

app.api.auth.login()[source]¶

Authenticates an administrator and starts a session.

Expected JSON Body:

{
    "username": "admin",
    "password": "admin123"
}

Returns:

{
    "success": true,
    "message": "Login successful",
    "user": {
        "username": "admin",
        "role": "administrator"
    }
}
Returns:

JSON response with authentication status.

Return type:

flask.Response

app.api.logging module¶

Logging API Module¶

This module provides endpoints for retrieving and filtering event logs, generating statistics, and accessing captured verification images.

app.api.logging.get_all_logs()[source]¶

Retrieves all logs with optional pagination.

Query Parameters:

  • limit (int): Number of results per page (default: 100).

  • offset (int): Number of results to skip (default: 0).

Returns:

{
    "success": true,
    "total": 500,
    "limit": 100,
    "offset": 0,
    "logs": []
}
app.api.logging.get_event_types()[source]¶

Retrieves a list of all possible event types used by the system.

app.api.logging.get_log_image(log_id)[source]¶

Serves the physical image file associated with a specific log entry.

app.api.logging.get_logs_by_employee(employee_id)[source]¶

Retrieves all logs associated with a specific employee.

URL Parameters:

  • employee_id (int): The ID of the employee.

app.api.logging.get_logs_by_event_type(event_type)[source]¶

Retrieves logs filtered by a specific event type.

URL Parameters:

  • event_type (str): The type filter (e.g., ‘INVALID_QR’).

Query Parameters:

  • limit (int): Results per page.

  • offset (int): Results skip count.

app.api.logging.get_logs_date_range()[source]¶

Retrieves logs within a specified date and time range.

Query Parameters:

  • start_date (str): Start date in ISO format.

  • end_date (str): End date in ISO format.

app.api.logging.get_statistics()[source]¶

Retrieves aggregated statistics of event counts grouped by type.

Returns:

{
    "success": true,
    "statistics": {
        "VERIFICATION_SUCCESS": 150,
        "FACE_MISMATCH": 12
    }
}

app.api.manage_employees module¶

Employee Management API Module¶

This module provides the Flask Blueprint and routes for CRUD operations on employees, QR code generation, and biometric data management.

app.api.manage_employees.activate_employee(employee_id)[source]¶

Sets an employee’s status back to active.

app.api.manage_employees.add_employee()[source]¶

Creates a new employee record in the database.

This endpoint initializes the employee profile but does not automatically generate a QR code or upload face images.

Expected JSON:

{
    "name": "Jan Kowalski",
    "position": "Engineer",
    "department": "IT"
}
Returns:

A success flag and the serialized employee dictionary.

Return type:

JSON

app.api.manage_employees.add_employee_face(employee_id)[source]¶

Uploads a face image and extracts biometric encodings for an employee.

Expects a multipart/form-data request with a file field named ‘image’. The system extracts the first detected face and stores it in one of the 5 available slots.

Parameters:

employee_id (int) – Target employee ID.

Returns:

Path to the stored image and the updated face count.

Return type:

JSON

app.api.manage_employees.deactivate_employee(employee_id)[source]¶

Sets an employee’s status to inactive (Soft Delete).

app.api.manage_employees.delete_employee(employee_id)[source]¶

Permanently deletes an employee and all associated files (Hard Delete).

Parameters:

confirm (str) – Query parameter. Must be ‘true’ to confirm deletion.

app.api.manage_employees.delete_employee_face(employee_id, face_index)[source]¶

Removes a specific face encoding and its image file from the employee.

Parameters:

  • employee_id (int) – Employee ID.

  • face_index (int) – Index (1 to 5) of the face slot to clear.

app.api.manage_employees.generate_employee_qr(employee_id)[source]¶

Generates a unique QR code hash for an employee.

This hash is used to generate the physical QR code for verification.

Parameters:

employee_id (int) – The unique ID of the employee.

Returns:

Success status and the generated QR hash string.

Return type:

JSON

app.api.manage_employees.get_employee(employee_id)[source]¶

Retrieves a single employee’s data by their ID.

app.api.manage_employees.get_employees()[source]¶

Retrieves a list of all employees in the system.

Parameters:

active (str) – Optional query param. ‘true’ (default), ‘false’, or ‘all’.

Returns:

A list of employee dictionaries.

Return type:

JSON

app.api.manage_employees.update_employee(employee_id)[source]¶

Updates basic employee details.

Allowed JSON fields: name, position, department.

app.api.verification module¶

Verification API Endpoints¶

Blueprints for verification-related API endpoints, handling QR code validation and face matching logic.

app.api.verification.QR_FOLDER = './static/qr_codes'¶

Path to the folder where generated QR codes are stored

app.api.verification.match_employee_face(employee_id)[source]¶

Matches a captured face image against the stored encodings for an employee.

Parameters:

employee_id (int) – The ID of the employee to verify.

Request:

Multipart/form-data with a file field named image.

Returns:

JSON indicating match status and the log ID.

{
    "match": true,
    "log_id": 123
}

Return type:

Response

app.api.verification.save_qr()[source]¶

Saves a generated QR code image to the local filesystem.

Expects a JSON payload with a base64 image, employee name, and ID.

Request Body:

{
    "image": "data:image/png;base64,...",
    "name": "Jan Kowalski",
    "id": 1
}
app.api.verification.verify_qr()[source]¶

Verifies a scanned QR code and logs the scan event.

Expects a JSON payload containing the QR hash and an optional image.

Request Body:

{
    "qr_data": "hash_qr_kodu",
    "image": "base64_encoded_image_optional"
}
Returns:

A JSON response and an HTTP status code.

{
    "success": true,
    "message": "Witaj! Jan Kowalski",
    "employee": {
        "id": 1,
        "name": "Jan Kowalski",
        "position": "Engineer",
        "department": "IT"
    }
}

Return type:

tuple
